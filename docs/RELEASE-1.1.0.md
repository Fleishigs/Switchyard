# Switchyard 1.1.0 — working in the file you selected

The common tool modal is replaced by a persistent workspace: selected input and actual processing targets match, batch processing is explicit, results remain beside controls, and outputs can be saved or reused without going through Queue. Windows file paths are deduplicated case-insensitively, including duplicate entries returned in one picker result. Same-name files show their parent folder or originating result.

Audio/video trimming adds whole-file initial bounds, In/Out timecodes with draft entry, playback/selection audition, frame-rate stepping, waveform/filmstrip navigation, zoom/pan, draggable handles, and adjustment undo/redo. Metadata loads before waveform extraction so a long waveform does not block the player. Video exports use accurate re-encoding. Frame stepping uses average frame rate, not VFR frame timestamps.

AI image enhancement now runs the actual local Upscayl NCNN engine with Lite, Standard and Digital Art models, at 2× or 4×, exporting PNG/JPEG/WebP. Tested on the machine's NVIDIA GTX 1050 Ti. PNG/WebP preserve alpha; JPEG flattens against white. The old enhancement operation is accurately named Adjust photo contrast. AI results are inferred details, not guaranteed reconstruction. Full output is retained; the detail viewer displays up to 4096 pixels.

Other workflow changes include visible ordered PDF/image inputs, stable PDF page entry, OCR-compatible file selection, colored text differences, source/result comparison, explicit saving, and result reuse.

Validation: 106 independent content contracts passed; the complete initial test command had 203 passes and one missing-engine fixture failure. After supplying the actual engine path, all 111 processing-suite tests passed (the other 93 had already passed). Separate real GPU tests cover three models, formats, transparency, dimensions, original preservation and cancellation. Real Electron journeys cover same-name video selection and decoded export pixels, audio selection playback and pointer dragging, PDF output ordering, AI export/compare/save/reuse, and text differences. Actual Windows Messages pickers, contact import, XML saving and restart persistence passed. Actual UI processing completed for 106 operations, with saved output files and the editor remaining open. Workspace routing was checked for all 111 common operations; the batch converter is the 112th registered tool.

This release does not claim to replace full GIMP, Audacity, Shotcut or PDFsam. The per-tool review in [TOOL-WORKFLOW-AUDIT.md](TOOL-WORKFLOW-AUDIT.md) records the remaining differences and testing boundaries. In particular, multitrack editing, multiple cut segments, saved processing recipes, direct live effects and page-thumbnail rearranging still need dedicated work.

This does not cover every possible file, option combination or hardware configuration.
